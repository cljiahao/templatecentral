Standard licence texts the comment gate lets a file-top comment quote without counting its lines. Lines before the first @@ marker are ignored, except the two id lists below.
Matching is on words only: case, punctuation, list numbers, comment markers and line wrapping are ignored. A copyright or SPDX line is exempt on its own and is not listed here.
A comment is exempt only when all its remaining words appear as one unbroken run of one text below, so one added sentence makes the whole comment count again.

The closed SPDX lists for the licence-ids: and exception-ids: lines: ids only, no texts. An SPDX line is exempt only when its expression is built from these ids. An exception id is valid only after WITH.
