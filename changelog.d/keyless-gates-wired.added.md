- Keyless gates wired into every scaffold: `licences`, `sbom`, `changesize` and `bundle` are rows in `.claude/gates.txt`, run from lefthook and both CI hosts (`bundle` reports a skip on stacks with no browser bundle; Python CI installs use a `.venv`); the four config files are copied by the manifest, frozen by `gate-ratchet.sh` (new `lines` and `bundle` kinds) and protected by protect-files; `verify-harness.sh` fails on an unregistered gate file (`GATE FILE UNREGISTERED`) or a CI gate with no `gates.txt` row (`GATE UNLISTED`); the five `seeded-*` tests run in the `keyless-gate-tests` CI job.
