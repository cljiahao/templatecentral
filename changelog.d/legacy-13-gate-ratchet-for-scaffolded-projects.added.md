- Gate ratchet for scaffolded projects: seeded offline `scripts/gate-ratchet.sh` compares tracked gate config with the merge base and fails a PR that weakens it (lower coverage threshold, higher complexity, duplication or test-ratio limit, a lint rule turned off or downgraded, a new ignore or exclude in lint, coverage, jscpd or gitleaks config, a gate removed from `.claude/gates.txt`). It prints file, old value and new value, and fails closed on a known config file it cannot parse. Runs as `ci-gates.sh ratchet` in the GitHub and Azure templates; a maintainer can bypass with the `allow-gate-change` label. Tested by `scripts/gate-ratchet.test.sh`, wired into `validate-skills.yml`.
