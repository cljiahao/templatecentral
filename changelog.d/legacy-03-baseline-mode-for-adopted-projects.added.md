- Baseline mode for adopted projects: `harness-refresh.sh --apply --gate-baseline` (bare `--baseline` as last argument works too) records existing lint, type-check, workflow and Dockerfile findings in one sorted `.claude/gate-baseline.txt` (gate, file, line-independent fingerprint, count) and copies `scripts/gate-baseline.sh`; the file lists every gate that ran with its tool (format v2; switching a gate off or changing its tool fails), a gate then fails only on findings not in the file, moved code passes, a second copy fails, fixed entries are reported removable and `--prune` drops them, a missing or corrupt file fails, and `growth` reports any added entry or raised count in the gate-ratchet format; a dry run writes nothing; wiring into `ci-gates.sh` and the ratchet follows.
