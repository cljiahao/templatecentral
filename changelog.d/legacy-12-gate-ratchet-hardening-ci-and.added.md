- Gate ratchet hardening: CI and `gate-ratchet.sh` run the merge-base copy of the checker (the head copy only on first adoption), so a PR cannot replace the script that judges it. Gate scripts and runners (`gate-ratchet.sh`, `ci-gates.sh`, `verify-harness.sh`, `test-budget.sh`, lefthook, the CI files, `gates.txt`) are ratcheted by content. Lint rules compare per config block, and a global `off` that only a test override had is a finding. New config files that compete with a ratcheted one and renames of known configs fail. Added ruff per-file-ignores forms, dotted ruff keys, gitleaks `disabledRules`, jscpd `minTokens`, `minLines`, `path`, `gitignore` and `skipLocal`, vitest `coverage.include` and config-level `eslint-disable`. A threshold that is not a plain decimal literal, or a duplicate JSON key, fails as unreadable. The `allow-gate-change` bypass prints every finding and a waiver line. `ci-gates.sh list` fails on a missing or empty manifest.
