- The here-string lint reads no shell syntax any more: a seeded pipefail script or hook that has `<<<` on any line fails with its file and line, except a full-line comment or a row in the `HERE_STRING_ALLOW` list in `lint-skills.sh` (exact file and line text; a row that matches nothing fails too). Heredoc and arithmetic guessing is gone, so no shift, quote or heredoc form can hide a here-string.
