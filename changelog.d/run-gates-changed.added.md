- Local changed-gates runner: `scripts/run-gates.sh --changed` maps the paths changed since the merge base (committed, staged, unstaged, untracked; NUL-safe) to the `bash scripts/…` and `node adapters/…` gates of every `pull_request` workflow through the data file `scripts/run-gates.map`, runs only those, and prints CPU seconds per gate; `--all`, `--list` and `--check` (the map against the workflows and the gate sources) are the other modes. When unsure it selects every gate: an unmapped path, any `skills/` change, and a change to the runner, the map or `.github/`. A run line it cannot read exactly (`python3 scripts/…`, `bash ./scripts/…`, a `cd scripts`) stops the run with exit 2 until the command is mapped or given an `@skip` row. `--check` audits the map: a gate script that names a mapped path must be selected by that path's row, or carry a reviewed `@noread` row. Each gate has a time limit (`RUN_GATES_TIMEOUT`, default 3600 s) and its process group is stopped on a timeout, a signal or an interrupt; a signal-killed gate is a FAIL; a pass that printed `SKIP:` lines is `PASS-WITH-SKIPS`; `GIT_*` repository variables are dropped; a scratch dir inside the repo is not a change. Tested by `scripts/run-gates.test.sh`, wired in the `shell-lint` job.
