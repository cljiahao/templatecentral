Seeded gate scripts no longer use here-string match tests, so a read-only temp folder cannot turn a failing gate into a pass. `verify-harness.sh` now fails naming any required gate whose `gates.txt` row is missing, and refuses a blank, missing or symlinked gate script; `ci-gates.sh` and the comment, duplicate-test and exclusion gates apply the same preflight, and the comment gate reads diffs that `.gitattributes` marks binary.
