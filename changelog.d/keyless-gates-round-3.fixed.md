- The change-size gate weighs a tracked text file by the larger of its git line count and one line per 4 KiB of its changed lines (one huge line, CR-only line ends, a huge added line or a deleted huge file can no longer weigh 2 lines; a one-line edit to a large file still weighs 2), reads paths that start with `-` as files, and the Python CI templates install the unhashed dev requirements only after every gate that does not need them (secret scan, change size, bundle size, duplication) and flag bare `pip`, `pip3`, `pipx` and `uv pip`.
- The change-size gate reads every changed file name literally (`GIT_LITERAL_PATHSPECS=1`), so names such as `:(glob)x` or `:(top)y` no longer hide a large file or make git fail, and it stops with exit 2 when git counts lines for a path whose diff has no hunk; the comment-hygiene and changed-line coverage gates in `ci-gates.sh` read names literally too. The `-I` guard in the CI template test also flags path-prefixed `pip`, `pip3` and `python` (`$PWD/.venv/bin/pip`, `/usr/bin/pip`).
