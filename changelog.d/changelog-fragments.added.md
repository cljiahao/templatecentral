- Changelog fragments: a PR now adds `changelog.d/<slug>.<category>.md` instead of editing `CHANGELOG.md`, so merges to main no longer conflict on the changelog. `scripts/changelog-assemble.sh <version> <date>` folds the fragments into a release section; `scripts/changelog-check.sh <base-ref>` and the `changelog-fragment.yml` workflow require one valid fragment per PR and reject edits to `CHANGELOG.md` (the release PR from the assemble script is the only exception).
