- Changelog fragments: a PR now adds `changelog.d/<slug>.<category>.md` instead of editing `CHANGELOG.md`, so merges to main no longer conflict on the changelog. `scripts/changelog-assemble.sh <version> <date>` folds the fragments into a release section; `scripts/changelog-check.sh <base-ref>` and the `changelog-fragment.yml` workflow require one valid fragment per PR, keep `## [Unreleased]` empty and reject edits to `CHANGELOG.md`. The release PR (assemble, plus the version bump in `plugin.json` and `harness.json`) is the only exception, and the check replays the assemble to hold it to that. The entries that were under `## [Unreleased]` are now `changelog.d/legacy-NN-*` fragments.
