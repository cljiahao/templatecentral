- `scripts/regen-golden.sh`: regenerates `tests/golden/*.sha256` from the hashes `check-golden.sh --emit-hashes` computes (one hashing path for both), keeps each file's header comments, prints what would change by default and writes with `--write`; the fence snapshots are touched only with `--fences`, and `--write` changes nothing unless every step succeeded. Tested by `scripts/regen-golden.test.sh` on a scratch copy of the repo.
