- Seeded gate manifest `.claude/gates.txt` (one gate per line: name, lefthook marker, CI marker) is the authority for required gates. `ci-gates.sh` runs only listed gates and has a `list` case; `verify-harness.sh` fails with `GATE MISSING` when lefthook, the GitHub workflow or the Azure files omit a listed gate. The manifest is hash-guarded and protected by `protect-files.sh`; `scripts/test-ci-templates.sh` and `scripts/test-harness-kit.sh` drop each gate from each runner and expect a failure.
