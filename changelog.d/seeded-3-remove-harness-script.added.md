- `scripts/remove-harness.sh`, seeded: removes only manifest-listed files that sit in a fixed allow list of seeded harness locations and whose content still equals the seeded hash; everything else (source, lockfiles, `.env`, `.gitignore`, `AGENTS.md`, any user file a manifest line names) is kept with a reason, as is any path with a symbolic link in any segment, `.git/`, absolute or `..` paths and entries holding a tab or newline (a manifest with any control character in a path or hash is refused whole). Dry run by default, `--apply` removes, `--force <path>` removes one locally modified allow-listed file. A second run after a full removal exits 0 with "already removed". When every file reads as modified it says the manifest hashes may be provisional. Restores nothing and lists the manual steps left. Tests: `scripts/seeded-remove-harness.test.sh`.
