- Known-defect report for projects built by older plugin versions: `skills/migrate/general/defect-report.sh [project-dir]` lists the older template patterns a project's source still carries (`file:line`, id, level, fix, current template path). It is read-only (never writes in the project, no login, key, token or network), has no version filter because a harness refresh rewrites the recorded version, and counts a check whose target file is absent as "not installed", never clean. One script per check in `skills/migrate/general/defects/`: `mongoose-client-promise-retry` (high), `redaction-tool-output` (high), `vite-auth-csrf` (high, cookie-mode backends), `mongoose-init-nextjs`, `mongoose-init-nestjs`, `argon2-dummy-hash-literal` and `sqlalchemy-tls-verify` (check level, verify first). Exit 0 for none or check-only, 1 for a high match, 2 when it cannot run. `skills/migrate/general/UPGRADE-NOTES.md` lists each pattern plus two review-by-hand items (NestJS roles guard, malformed JSON). The migrate skill and the standards drift check run it and change source only after the user confirms each fix. `scripts/defect-report.test.sh` flags each check's old fixture under `tests/fixtures/defects/` and keeps the current template file clean; not wired into CI yet.
