- Gate-time budget in every scaffold: `.claude/ci-gates.sh` records each gate's name, seconds and exit status (bash 3.2 safe, atomic write, never changes a gate's output or exit status) in the git-ignored `.claude/gate-times.tsv`, and the new `.claude/gate-budget.sh` checks it against `.claude/gate-budget.conf` (`total_budget_seconds`, `per_gate_budget_seconds`, `regression_percent`, `runs_kept`; allow-listed integer keys, a broken record or config fails closed with exit 2). Over budget it prints a note of at most 12 lines: total against budget, the three slowest gates and the allowed remedies (cache, parallel gates, affected-only local tests, smaller Docker context, faster test setup; removing or skipping a check is not one); it warns and never blocks. The SessionStart hook shows it once per session, the GitHub `quality` job and the Azure gates template print it in the job log, and the gate ratchet fails a raised budget or a deleted config (new `gatetime` kind). A failed run is left out of the regression median, so a fast-failing gate never looks fast. No login, key or hosted service. Tested by `scripts/gate-budget.test.sh`, with guard-removal probes.
